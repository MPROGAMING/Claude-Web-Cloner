# Template banner artwork

Each genre banner is a crop of the composed sample render published on the
pack's own page at kenney.nl. Every pack below states **License: Creative
Commons CC0** on its page — public domain, commercial use permitted,
attribution not required. Credited anyway.

The bottom ~70px of each source render carries a CC0 badge, licence text and a
KENNEY wordmark; every crop stops above row 440 of the 515px source, so none of
that survives. Crops are uniform-scale (2.8:1 band, output 900x321, JPEG q84) —
nothing is stretched.
